# Credits

ornith-launcher is an unofficial project that builds on the work of others. None of them is affiliated with it.

| Project | What it provides | Licence |
|---|---|---|
| [Ornith AI](https://huggingface.co/ornith-ai) | The Ornith models (1.0 and 1.5) | MIT, as declared in the model metadata |
| Community quantizers on Hugging Face (for example bartowski, unsloth, mradermacher, dealignai) | GGUF builds of the Ornith models, listed in the catalog by repository | Each repository's own licence |
| [Qwen3.5](https://huggingface.co/Qwen) | Base models named on the Ornith cards | Apache-2.0 |
| [Gemma 4](https://huggingface.co/google) (Google) | A base model named on the Ornith 1.0 card | Apache-2.0, as declared on Google's Hugging Face repositories |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) by ggml.org | The inference server, run from its official Docker images on Linux and its release build on macOS | MIT |
| [Hugging Face](https://huggingface.co) | Model hosting and the public API the catalog reads | Hugging Face terms of service |
